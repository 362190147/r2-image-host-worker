直连 Worker 接口调试 ← 返回上传页

GET /api/config 匿名

读取公开配置（上传模式、外链前缀、单文件上限、是否需要鉴权）。

GET /api/health 需上传口令

健康检查 + 完整配置状态（桶名、模式、上限、删除是否启用、key 前缀）。

GET /api/diag 需上传口令

配置体检：回报哪些 env 存在（不回报值）、lint 问题、可选定点 key 诊断。

GET /api/list 需上传口令

历史图片清单（列桶），最新在前。受口令保护。

POST /api/upload 需上传口令

上传图片。multipart/form-data，字段名 file，支持多文件。可附带 redirect / verify。

POST /api/delete 需删除口令

删除图片。只接受以 KEY_PREFIX/ 开头、不含 .. 与 // 的 key。
